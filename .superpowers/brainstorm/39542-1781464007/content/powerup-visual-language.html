Power-Up Visual Language

Which direction should Maze Runner power-ups use? Click one, or answer in chat.

A. Signal Hacks

Keep the current hacker/arcade fantasy. Standardize each pickup around a dark core, neon stroke, signal socket, and unique animated glyph.

B. Arcade Relics

Reframe pickups as collectible chips/gems. More readable at maze scale, but less connected to the existing hack progression and HUD language.

C. Combat Tools

Make each pickup feel like active equipment. Strong action readability, but risks making Maze Runner feel more like an action game.
